# FIT_Travel_Itenerary

## BACKEND SETUP

### Install requirements
```cd backend```

```pip install -r requirements.txt```

### API SETUP
Create a ```.env``` file in the ```backend``` folder and add your API keys there.
For reference check ```/backend/.env.example```

### Run
```uvicorn main:app --reload```
