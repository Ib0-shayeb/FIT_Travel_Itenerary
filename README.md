# FIT_Travel_Itenerary

# SETUP
## Install requirements
```pip install -r requirements.txt```
## BACKEND SETUP

### API keys
Create a ```.env``` file in the ```backend``` folder and add your API keys there.
For reference check ```/backend/.env.example```

### Run
```cd backend```

```uvicorn main:app --reload```

### API Testing
http://localhost:8000/docs#/

## FRONTEND SETUP
### Install requirements
```cd frontend```

```npm install```
### Run
```cd frontend```

```npm run dev```
