# FIT Travel Itinerary App

A full-stack travel itinerary planning application built with:

* React + Vite
* FastAPI
* React Leaflet Maps
* Google Places API
* Duffel Flight API

---

# Frontend Setup

```bash id="u7m2q5"
cd frontend/frontend-app
npm install
npm run dev
```

Frontend runs on:
http://localhost:5173

---

# Backend Setup

Install dependencies:

```bash id="n4x8v1"
pip install fastapi uvicorn
```

Run backend:

```bash id="r9k3w6"
cd backend
python -m uvicorn main:app --reload
```

Backend runs on:
http://127.0.0.1:8000
